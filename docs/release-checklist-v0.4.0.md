# MemoEZ v0.4.0 リリースチェックリスト（ホーム画面ウィジェット）

## 自動検証（CI / ローカル）

- [ ] `npx tsc --noEmit`
- [ ] `npm run lint`
- [ ] `npm test`
- [ ] GitHub Actions「Android Build」: `expo prebuild` → `assembleDebug` → `lintDebug`
- [ ] 同上「Verify home screen widget is packaged」: APK にウィジェットのクラスと、マージ後マニフェストの Provider / Activity / appwidget メタデータが含まれる

## 実機確認（CI では検証できない項目）

ランチャー・ウィンドウ表示・プロセス管理は端末ごとに差があるため、実機で確認する。
推奨: Android 12 以降の端末 1 台以上 + Android 8〜11 の端末（またはエミュレータ）1 台。

### ウィジェットの追加・削除
- [ ] ウィジェット一覧に「MemoEZ 付箋」が表示される（Android 12+ はプレビュー付き）
- [ ] 追加するとメモ選択ウィンドウが開き、背後にホーム画面が見える
- [ ] メモを選ぶとウィジェットにタイトル・本文（またはチェックリスト）・メモの色が表示される
- [ ] 選択せずに閉じる（×・戻る・外側タップ）と、ウィジェットは追加されない
- [ ] 2 個以上配置し、それぞれ別のメモを表示できる。同じメモを 2 個に表示することもできる
- [ ] ウィジェットを削除しても、他のウィジェット・メモに影響しない
- [ ] Android 12+: ウィジェットを長押し →「再設定」で表示するメモを変更できる

### 表示
- [ ] サイズを変えると本文・チェックリストの表示行数が変わる（小さいときは期限・進捗の行を省く）
- [ ] チェック済み項目は打ち消し線、フッターに「n / m 完了」と期限が出る
- [ ] 端末のライト / ダーク切り替えでウィジェットの配色が追従する（Android 12+）。Android 11 以前は次の更新時に追従

### フローティング編集
- [ ] ウィジェットをタップすると、ホーム画面を背後に残したまま編集ウィンドウが開く（MemoEZ 本体の画面が背後に出ない）
- [ ] タイトル・本文の編集、テキスト ⇄ チェックリスト切り替え、項目の追加・編集・チェック・削除
- [ ] ラベル選択・ラベル管理（ウィンドウ内に重ねて表示され、戻るで編集に戻る）
- [ ] カラー変更、期限の設定・解除、ピン留め、削除（確認ダイアログ → ウィジェットが「削除されました」表示）
- [ ] キーボード表示時に入力欄が隠れない（カードが縮む）
- [ ] 戻る / × / 外側タップで、保存してからホーム画面に戻る。入力直後（1 秒以内）に閉じても内容が残る
- [ ] 入力直後（1 秒以内）にホームボタン・履歴ボタンを押しても、ウィンドウが閉じた後に内容が保存され、ウィジェットにも反映されている
- [ ] 上記の直後にアプリをタスク一覧から終了しても、入力内容が残っている
- [ ] （可能なら）保存に失敗する状況（ストレージ満杯など）で閉じようとすると、閉じずに「保存できませんでした」が表示され、入力が残る。ホームボタンで離れた場合は履歴からウィンドウに戻れる。「破棄して閉じる」で閉じられる
- [ ] 閉じた後、ウィジェットに編集結果が反映される
- [ ] ダークモードでウィンドウ・ダイアログが読みやすい
- [ ] 最近使ったアプリ一覧にウィンドウが残らない

### 通常アプリとの併用
- [ ] アプリでメモを編集・削除・ピン留め・カラー変更すると、ウィジェットに反映される
- [ ] アプリで同じメモを開いたまま裏に回し、ウィジェットから編集 → アプリに戻ると最新の内容が表示され、古い内容で上書きされない
- [ ] JSON / Google Drive からの復元（上書き）後、元のメモを表示していたウィジェットは「削除されました」表示になり、タップで選び直せる
- [ ] 既存のメモ機能（作成・検索・ラベル・期限・バックアップ）が従来どおり動く
- [ ] ウィジェットからウィンドウを開いた後にアプリ本体を起動しても、通常どおりホーム（メモ一覧）が表示される（不正なディープリンク扱いにならない）

### プロセス終了・再起動
- [ ] アプリをタスク一覧から終了 → ウィジェットの表示が残り、タップで編集できる（初回は読み込み表示の後に開く）
- [ ] 端末再起動後もウィジェットの内容が表示され、タップで編集できる
- [ ] アプリを更新インストールした後もウィジェットが表示される
