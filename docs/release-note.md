## v0.2.0（ドラフト）

### Title
`v0.2.0: 検索・自動保存の既存バグ修正とリファクタリング`

### Note
MemoEZ `v0.2.0` は新機能追加ではなく、ソースコード全体レビューで見つかった既存バグの修正とリファクタリングを行うリリースです。

#### バグ修正
- 検索: `LIKE` のワイルドカード（`%` `_`）を未エスケープのまま埋め込んでいたため、「100%」のような入力を含む検索が全件ヒットしていた（`ESCAPE` 句付きでエスケープするよう修正）
- 検索: 検索条件をクリアした際にリクエストのシーケンス番号を採番しておらず、実行中の古いリクエストの結果が後から流れ込んで表示されることがあった
- 検索: ラベル絞り込みのみで 0 件のとき `"" は見つかりませんでした` と表示されていた（キーワード有無で文言を出し分け）
- 検索: リポジトリ側の検索対象にラベル名が含まれておらず、「ラベル + キーワード」検索時のクライアント側フィルタと挙動が食い違っていた
- 編集画面: 変更が無くても自動保存が走り、メモを開いただけで `updatedAt` が更新されて一覧の並びが変わっていた（保存対象のスナップショット比較で抑止）
- 編集画面: 保存中に届いた変更が破棄され、そのまま操作が止まると最後の編集内容が永続化されないことがあった（保存完了後に再保存をスケジュール）
- 編集画面: マウント判定用の ref が effect 再実行後に `false` のままになり、StrictMode / Fast Refresh 後に画面の状態更新が止まる可能性があった
- 編集画面: ラベル付与のために自動生成した空メモが、そのまま画面を閉じても一覧に残っていた（破棄するよう修正）
- チェックリスト: 保存のたびに全アイテムを論理削除して作り直す実装のため、墓石行が無制限に増え続けていた（1 世代のみ残して物理削除）
- ホーム画面: セクション見出しの色がテーマ切り替えに追従しない箇所があった
- バックアップ: 壊れた JSON や欠損フィールドを含むファイルをインポートすると途中で例外終了し、DB に中途半端な状態が残ることがあった（取り込み前に各項目を正規化）
- `expo-file-system` が `package.json` に未宣言のまま使用されていた（推移的依存に依存していたのを明示的な依存に追加）

#### リファクタリング
- 一覧取得時の関連行（チェックリスト/ラベル）の突き合わせを Map によるグルーピングに変更
- DB 行 → ドメインエンティティ変換の Date 変換処理を `toDate` / `toNullableDate` に集約
- 未使用だった `lib/result.ts` を削除。未使用のまま放置されていた `nextSortWeight()` / `buildDueDatePresets()` を実際の呼び出し元に接続
- 自動保存の待ち時間などのマジックナンバーを定数化
- 実装と食い違っていたドキュメント（FTS5 全文検索の記載、BottomTab ナビゲーションの記載、テーマ設定の永続化に関する記載、テーブル定義）を実装に合わせて修正

#### テスト
- LIKE パターンのエスケープ、フォームのスナップショット比較、バックアップ項目の正規化についてユニットテストを追加（10 suites / 37 tests）

#### 互換性
- DB スキーマ変更なし。既存データはそのまま利用可能。

### 注意事項
- 本リリースは内部品質改善が中心のため、ユーザー向けの新機能はありません。

## v0.1.7（ドラフト）

### Title
`v0.1.7: テキスト⇄チェックリスト変換の改善`

### Note
MemoEZ `v0.1.7` の変更ドラフトです。

#### 主要改善
- テキスト ⇄ チェックリスト の相互変換を改善
  - テキスト → チェックリスト: 空行区切り（段落単位）でアイテム化
  - チェックリスト → テキスト: 箇条書き（`• `）形式で本文を生成

#### 期待される効果
- メモ形式の切り替え時に内容を初期化せず、利用者の入力意図を保持できる。

## v0.1.6

### Title
`v0.1.6: 期限・通知とバックアップI/Oを強化した安定化リリース`

### Note
MemoEZ `v0.1.6` は「期限・通知」「バックアップI/O」を実利用向けに強化したリリースです。実機確認で得たフィードバックを反映し、日時入力 UI とバックアップ導線を改善しました。

#### ハイライト
- 期限・通知
  - `dueAt` / `reminderAt` の保存・表示・更新を全体で対応
  - 期限設定 UI を改善（カレンダー日付選択 + 時/分選択）
  - 期限解除・通知ガイド表示を整備
  - 期限順ソート（期限未設定は後ろ）と期限切れ表示（色・アイコン）
  - リマインダースケジューラ（抽象レイヤ）を追加し、保存/更新/削除時に再設定
- バックアップI/O
  - JSON export/import（merge / overwrite）を実装
  - 保存先/読込先フォルダの選択をサポート（初期値: Download）
- 安定化
  - DB 後方互換 migration
  - リポジトリの soft-delete 安全性向上
  - テスト拡充（backup / scheduler / search / sort / label）

#### 主な確認観点
- 期限の設定・変更・解除、カレンダー日付選択と時分選択
- backup export/import（merge / overwrite）
- 既存データからの更新後互換性

### 互換性
- App Version: `0.1.6`
- Target Tag: `v0.1.6`

### 注意事項
- OS ネイティブ通知連携（expo-notifications）は後続フェーズで対応予定。
