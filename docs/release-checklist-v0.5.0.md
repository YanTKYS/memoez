# MemoEZ v0.5.0 リリースチェックリスト（4×2 一覧ウィジェット）

## 自動検証（CI / ローカル）

- [ ] `npx tsc --noEmit`
- [ ] `npm run lint`
- [ ] `npm test`
- [ ] GitHub Actions「Android Build」: `expo prebuild` → `assembleDebug` → `lintDebug`
- [ ] 同上「Verify home screen widget is packaged」: 2×2 / 4×2 の Provider、一覧の Service（BIND_REMOTEVIEWS 保護）、ウィンドウ用 Activity が APK に含まれる

## 実機確認（CI では検証できない項目）

推奨: Android 12 以降の端末 1 台以上 + Android 8〜11 の端末（またはエミュレータ）1 台。ランチャーにより挙動が異なるため、可能なら端末標準以外のランチャーでも確認する。

### 一覧ウィジェットの追加・表示
- [ ] ウィジェット一覧に「MemoEZ 一覧」が表示され（Android 12+ はプレビュー付き）、設定画面なしで 4×2 で配置できる
- [ ] ピン留めしたメモが先頭、その後は更新日時の新しい順に並ぶ。アーカイブ・削除済みのメモは出ない
- [ ] 各行にタイトルと本文冒頭（タイトルが空なら本文 1 行目）が出る。チェックリストは「n/m 完了・未完了項目」
- [ ] メモのカラーが行の左端の帯に出る（デフォルト色は帯なし）。ライト / ダークで配色が切り替わる
- [ ] 縦スクロールで 50 件まで閲覧できる（51 件以上あっても 50 件まで）
- [ ] メモが 0 件のとき「メモはありません」が出る
- [ ] サイズを変えても表示が崩れない（幅・高さとも）

### 編集・反映
- [ ] 行をタップすると、そのメモのフローティングエディタが開く（ホーム画面が背後に見える。別のメモが開かない）
- [ ] スクロールした後の行（20 件目など）をタップしても、正しいメモが開く
- [ ] 編集して閉じると、一覧の内容と並び順（編集したメモが先頭へ）が更新される
- [ ] アプリでメモを作成・編集・削除・ピン留め・アーカイブすると一覧に反映される
- [ ] 一覧から開いて閉じた後にアプリ本体を起動しても、通常どおりメモ一覧が表示される

### プロセス終了・再起動
- [ ] アプリをタスク一覧から終了しても一覧が表示され、行のタップで編集できる
- [ ] 端末再起動後も一覧が表示され、行のタップで編集できる
- [ ] アプリを起動していない状態で一覧ウィジェットを初めて配置すると「MemoEZ を開くと一覧を表示します」が出て、タップでアプリが開き、一覧が表示される

### 既存の付箋ウィジェット（2×2）の回帰
- [ ] 付箋ウィジェットの追加・メモ選択・表示・編集・削除時の表示が従来どおり
- [ ] 付箋と一覧を同時に配置し、片方で編集した内容がもう片方にも反映される
- [ ] 付箋ウィジェットをすべて削除しても、一覧ウィジェットの表示が消えない（逆も同様）
