# MemoEZ v0.1.6 計画（機能追加版）

最終更新: 2026-04-19

## リリーステーマ
- 期限・リマインド機能
- インポート・エクスポート機能

## 主要要件

### 1) 期限・リマインド
- メモごとに期限日時を設定できる
- 期限順での一覧表示・検索補助
- ローカル通知によるリマインド（即時/当日/前日など）
- 通知許可が無効な場合のフォールバックUI

### 2) インポート・エクスポート
- JSON 形式でのバックアップエクスポート
- JSON 形式での復元インポート
- ラベル・チェックリスト・アーカイブ状態を含む
- 重複インポート時の挙動（マージ/上書き）を定義

## 技術的タスク（初期）
1. ドメイン拡張
   - `Note` に `dueAt`, `reminderAt`（nullable）を追加
2. DBスキーマ更新
   - `notes` テーブルへ期限・通知カラム追加（migration）
3. 通知基盤
   - スケジュール通知の抽象化レイヤ追加
4. データ移行
   - 既存ノートとの後方互換（null 初期値）
5. バックアップI/O
   - export/import ユースケースとバリデーション実装
6. テスト
   - 期限ソート・通知スケジュール・import/export 回帰テスト

## 完了条件（Definition of Done）
- 期限設定、通知、import/export の主要フローが E2E で動作
- 既存データを壊さずアップデート可能
- 失敗時のリカバリ（通知未許可、壊れたJSON）をUIで案内
